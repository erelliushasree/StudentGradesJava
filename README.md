# Student Grades Java Program

This is a simple Java console application that allows a teacher to enter student grades and then calculates:

- ✅ Average grade  
- ✅ Highest grade  
- ✅ Lowest grade

The program uses an `ArrayList` to store and process student data.

---

## Features

- Input grades for multiple students
- Automatically calculates average, highest, and lowest grades
- Simple and user-friendly console interface

---

##  Technologies Used

- Java
- ArrayList
- Scanner for input

---

##  How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/StudentGradesJava.git
   cd StudentGradesJava

Compile the Java program:

javac StudentGrades.java

Run the program:

java StudentGrades
